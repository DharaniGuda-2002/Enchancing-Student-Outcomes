# Enhancing Student Outcomes Through Predictive Modeling and Recommendation

## Overview
This project uses predictive modeling to analyze student learning behavior and academic performance, and generates personalized recommendations to improve student outcomes. Using historical educational interaction data, the system identifies patterns that influence performance and suggests targeted interventions for students.

## Dataset
The project uses the **SkillBuilder 2009–2010 dataset**, which contains detailed logs of student interactions, problem attempts, and skill mastery.

Dataset link:  
https://www.kaggle.com/datasets/nicolaswattiez/skillbuilder-data-2009-2010

## Approach
- Cleaned and preprocessed raw student interaction data
- Engineered features such as attempt counts, correctness rates, and skill progression
- Trained predictive models to estimate student performance and learning trends
- Built a recommendation module to suggest focus areas and learning actions based on model predictions

## Outputs and Results
- Model predictions indicating student performance levels and learning gaps
- Feature importance insights highlighting key factors affecting student outcomes
- Personalized recommendations for improving learning efficiency
- Visualizations and analysis outputs generated through Jupyter notebooks
